# manuellerchner.github.io

The root page of my GitHub Pages host. It gives the host a favicon and a name
for search results, and links to [manuellerchner.de](https://manuellerchner.de/).

Project sites under this host are served from their own repositories.

`sitemap.xml` lists the homepage and the Voblint landing page. The host-root
`robots.txt` advertises this sitemap and Voblint's generated sitemap, which
lists its individual pages and documents.
